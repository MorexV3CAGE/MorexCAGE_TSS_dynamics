# Neutral public workflow scripts

These scripts are neutral, publication-oriented versions of the promoter motif-analysis workflow.
User-specific paths and old internal script labels were replaced by generic environment variables and neutral output directories.

The workflow contains only analyses intended for the manuscript. The exploratory opposite-variant module-pair permutation analysis was removed.

## Script order and dependencies

### Known TFBS-family module branch

1. `01_prepare_known_tfbs_window_overlaps.sh`
   - Converts positive/background FASTA headers to BED windows.
   - Intersects those windows with a genome-wide known TFBS BED file.
   - This script requires positive/background FASTA files. They can either be precomputed or generated by script 03.

2. `02_known_tfbs_module_enrichment_and_variant_specific.R`
   - Uses outputs from script 01.
   - Merges overlapping same-family TFBS hits into blocks.
   - Defines local TFBS-family modules using a 10-50 bp gap.
   - Tests module enrichment in positive vs background windows.
   - Tests whether enriched modules are variant-specific or shared between long and short promoter variants.

### De novo STREME motif branch

3. `03_prepare_streme_inputs_and_run_script.R`
   - Prepares positive/background BED files for 50-150 bp upstream promoter windows.
   - Generates `run_streme.sh`, which extracts FASTA sequences and runs STREME.

4. `04_scan_streme_motifs_with_fimo.sh`
   - Uses STREME output from script 03.
   - Extracts STREME motifs 1-4 and scans positive/background FASTA files with FIMO.

5. `05_streme_motif_enrichment_and_variant_specific.R`
   - Uses outputs from script 04.
   - Tests STREME motif enrichment in positive vs background windows.
   - Tests long vs short motif presence and variant-specific/shared motif occurrence.

## Typical execution

```bash
source config_example.sh

# De novo motif branch
Rscript 03_prepare_streme_inputs_and_run_script.R
bash "$STREME_DISCOVERY_OUTPUT_DIR/commands/run_streme.sh"
bash 04_scan_streme_motifs_with_fimo.sh
Rscript 05_streme_motif_enrichment_and_variant_specific.R

# Known TFBS-family module branch
bash 01_prepare_known_tfbs_window_overlaps.sh
Rscript 02_known_tfbs_module_enrichment_and_variant_specific.R
```

The known-TFBS branch can be run after script 03 if it should use the same generated FASTA files, or it can be run independently if positive/background FASTA files are provided directly.

## Configuration in R/RStudio/Jupyter

For R scripts, set equivalent environment variables using `Sys.setenv()`, for example:

```r
Sys.setenv(PROJECT_DIR = "/path/to/project")
Sys.setenv(RESULTS_DIR = "/path/to/project/results")
Sys.setenv(CAGE_PROMOTER_TABLE = "/path/to/project/input/cage/all_cage_promoters.bed")
Sys.setenv(SHIFT_PROMOTER_TABLE = "/path/to/project/input/shift_promoters/shift_promoter_variants.bed")
Sys.setenv(GENOME_FASTA = "/path/to/project/input/genome/reference_genome.fa")
Sys.setenv(MEME_SIF = "/path/to/meme.sif")
```

## Notes

- Analytical logic, thresholds, Fisher/binomial tests, and module definitions were preserved.
- Output names were changed to neutral names.
- The STREME branch includes preparation of the STREME input sequences and the generated STREME run script.
